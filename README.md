# 六上数学乐园 · 青岛版

一个专为青岛版（六三制）**六年级上册数学**做的单文件学习应用：`index.html` 一个文件，浏览器打开即用，**断网可用、数据只存本机、完全免费、无任何追踪**。

> 同步 2025-2026 学年青岛版新教材目录：分数乘法 → 可能性 → 分数除法 → 比 → 圆 → 分数四则混合运算 → 百分数(一) → 总复习。

## 功能

| 模块 | 说明 |
|---|---|
| 📚 按单元学 | 18 张原创知识卡（意思+例子+易错口诀），过关检验做对点亮 |
| 🎲 智能出题器 | **108 个原创出题生成器**，数字随机、答案现算，永远做不完；基础/提高/挑战三档难度 |
| 📝 应用题特训 | 每单元 6~17 个应用题情境模板，一键 20 题连刷 |
| 📕 错题本 | 答错自动收，**隔日到期重考**，通过打勾 |
| 📋 两分钟摸底 | 每单元 1 题共 7 题，哪弱先学哪 |
| 🗺 一图看全册 | 知识全景 + 点亮进度 |
| 🧩 按板块攻 | 数与运算 / 图形与几何 / 统计与概率 |
| 📖 速查大表 | 20 条概念：白话解释 + 数字例子 |
| 🪜 应用题四步法 | 圈一圈 → 画示意图 → 列式 → 验算 |
| 📊 家长报告 | 各单元正确率、薄弱预警、最近 7 天练习量 |
| ⏭ 连续模式 | 一组做完 5 秒倒计时自动换全新一组，随时可停 |

## 使用

1. 把 `index.html` 发到孩子的设备（手机/平板/电脑）；
2. 用任意现代浏览器打开；
3. 写下名字，开始学习。

**部署为家庭服务（可选）**：`deploy/` 目录里有 docker-compose 与 nginx 配置，`docker compose up -d` 即可在局域网内供全家访问（端口 8766）。

## 出题生成器

每道题由"生成器"现场编造：随机取数 → 现算答案 → 生成干扰选项（故意埋常见错点）→ 附大白话解析。所以没有题库可背、没有重复打卡，同一模板每天出现的数字都不一样。

题型参照了《培优课堂》（青岛版同步）的"基础/提升/拓展"三段结构与《周计划·数学应用题强化训练》的经典应用题类型（行程归一、双单位 1、工作效率比、各种百分率等），**全部题面为原创**。

## 技术细节

- 零依赖、零构建：原生 JS 单文件，约 110KB；
- 进度存 `localStorage`（`qd6_state`），清浏览器缓存会丢进度；
- 分数以"分子在上、分母在下"的教科书样式渲染（`rich()` 渲染层，答案判定仍接受 `3/4` 或 `0.75`）；
- 可通过修改文件内的 `UNITS` / `GENS` 结构自行扩展知识点与题型。
