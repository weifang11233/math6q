# 六上数学乐园 · 青岛版（童趣版）

一个专为青岛版（六三制）**六年级上册数学**做的单文件学习应用：`index.html` 一个文件，浏览器打开即用，**断网可用、数据只存本机、完全免费、无任何追踪**。界面为童趣皮肤（奶油蓝天、小狗阿黄和小猫咪咪）。

> 已按 2026 年新版真课本逐章重建目录：分数乘法 → 分数除法 → 比 → 圆 → 解决问题 → 可能性 → 方向与位置 → 回顾整理·总复习。

## 使用

1. 把 `index.html` 发到孩子的设备（手机/平板/电脑），用任意现代浏览器打开；
2. 手机号注册（11 位、1 开头；密码恰好 10 位，含数字+大写+小写+特殊符号），登录后开始学习；
3. 永久使用请用**系统浏览器**打开；IDE 预览面板 / 隐私模式会禁用本地存储，此时自动降级为内存模式并在页面顶部提示。

**家庭局域网服务**：`deploy/` 有 docker-compose 与 nginx 配置，`docker compose up -d` 即可在 `http://<NAS地址>:8766/` 供全家访问。当前部署在飞牛 NAS `vol3/1000/docker/shuxueleyuan/site/index.html`（端口 8766）。更新时只需覆盖该目录下的 `index.html`，nginx 静态挂载即时生效，无需重启容器。

## 出题生成器

每道题由"生成器"现场编造：随机取数 → 现算答案 → 生成干扰选项（故意埋常见错点）→ 附大白话解析。所以没有题库可背、没有重复打卡，同一模板每天出现的数字都不一样。

题型参照了《培优课堂》（青岛版同步）的"基础/提升/拓展"三段结构与《周计划·数学应用题强化训练》的经典应用题类型（行程归一、双单位 1、工作效率比、各种百分率等），**全部题面为原创**。

## 技术细节

- 零依赖、零构建：原生 JS 单文件，约 176KB（含童趣皮肤 CSS 覆盖层）；
- 账号表 `qd6_users`（加盐 SHA-256 哈希 + 双滚动备份 `qd6_users_bak1/bak2`，主表损坏自动恢复）；每个用户的学习进度独立存 `qd6_state_<手机号>`；
- 存储不可用时自动降级内存模式（`lsProbe()` 探测 + 页面横幅提示），不误报"存储空间不足"；
- 分数以"分子在上、分母在下"的教科书样式渲染（`rich()` 渲染层，答案判定仍接受 `3/4` 或 `0.75`）；
- AI 判分走 OpenAI 兼容接口，内置 10 个推荐模型（7 个支持视觉）。**页面源码不含任何 API Key，也不含网关地址**；
- **默认走 NAS 同源代理 `/ai/`**（推荐）：Key 只写在 NAS 服务端 `nginx.conf`，由反向代理转发时注入 `Authorization`。管理员面板首次只需点「保存配置」（Key 留空），孩子的所有设备都能用 AI 判分，浏览器里没有任何密钥。代理配置见 `deploy/nginx.conf`；
- 也支持直连模式：管理员把接口地址改成完整网关地址并自填 API Key，此时 Key 只存当前浏览器 `localStorage`（密码框 + 掩码，不回显明文）、不随页面下发、不进导出的用户备份；未配置时自动降级为按最终答案判分；
- 权限：`go()` 统一导航网关 + 11 个功能入口的 `permGate()` 守卫，双重防绕过；
- 可通过修改文件内的 `UNITS` / `GENS` 结构自行扩展知识点与题型。
